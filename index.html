🎧 音频转谱
📜 歌名词库
支持 mp3 / wav / m4a 等。建议上传 30–90 秒清唱或伴奏片段。所有分析在你浏览器本地完成，音频不会上传任何服务器。 想从任意歌曲翻译？直接选你电脑里的音频即可。

内置示例：《青花瓷》《月亮代表我的心》《童年》。未收录的歌请用「音频转谱」，或在 data/songs.json 补充。
关于本工具 / 部署到 GitHub
• 音频转谱：浏览器内用 Web Audio 解码 + 自相关音高(YIN) + FFT 色度匹配，完全离线免费；已加离线精度增强（八度连续校正 + 和弦精炼）。
• 支持多乐器：吉他/尤克里里（和弦图+六线谱）、钢琴（键盘图 + 高音五线谱）、笛子（简谱+唱名 + 指法图）。
• 从任意歌曲翻译：在「音频转谱」选你电脑里的音频，本地离线转谱，无需上传。
• 导出谱面：生成结果后点「🖼 PNG / 📄 PDF」一键导出（首次需联网加载截图库）。
• 想更高精度？在「音频转谱」勾选「高精度模式」，或在 js/transcribe.js 接入 Basic Pitch(TF.js)，详见 README「高精度模式接入」。
• 部署到 GitHub Pages：把本仓库推送到 GitHub，在仓库 Settings → Pages 选择 main 分支根目录即可，个人免费无限流量。
